## v0.0.3（预备，2026-09-12）

> 本版**无破坏性条目**：无物品/流体 id 移除，旧存档可直接升级。

### 【增量】

- **魔源子素摄取仪（魔力再锻 · Ars 第一机）**
  - 新多方块（7×7×5 镂空塔，无 EU、无电压）：把 Ars 魔源浆果（`ars_nouveau:sourceberry_bush`）
    转化为魔源，存入内部 **50,000** 源池（= 5× 魔源罐）
  - 新配方类型 `gtnecore:source_extraction`（输入 1 / 无输出）：默认配方
    **源浆果丛 ×16 → 448 魔源**（28/颗，菌丝公式）· 200t · 0 EUt——16 并行通道一轮的
    配方化表达，扩展新产源材料只需加配方
  - 机器侧实现 Ars `ISourceTile` 并注册 `SourceManager`：5~10 格内的 Ars 方块可直接抽源池；
    成型期每 600t 幂等重注册（抗 Ars 侧 provider 清理）
  - GTM 风格机器 UI（源池 n/50000、萃取进度、待机提示）
  - 顶环 16 格成型后隐形：新增**结构透明化机制**（`StructureGhostBlock` 幽灵占位 + 成型重检
    按"隐藏前原方块"判定）——结构不解体、占位不可破坏/不可被放置覆盖，解体时自动还原原方块
    （材料不丢）；机制为通用钩子，后续机器可复用
  - 顶环/魔源球由两个 DynamicRender 呈现：VoxelBridge 区域导出 → 复用 glTF 管线
    （魔力环 + 中央魔源球，球体半径随池量缩放）
  - 配套 **至高木输入总线**：ULV 真输入总线（1 槽、`IMPORT_ITEMS`、标准输入面渲染）——
    魔力再锻系列的低压投料口
- **AE2 样板携带虚拟电路号（全链路）**
  - 编码终端：处理样板编码格中的编程电路被"虚拟化"——从样板输入列表移除，号数写入自定义
    NBT 键 `gtnecore_circuit`；AE2 网络不消耗、不感知电路（编码格配置保留不丢）
  - 样板供应器：推送样板时把号自动写入目标机器（各面 `IHasCircuitSlot`）的幽灵电路槽
    （号相同则跳过）——**一张样板 = 一条产线切换指令**，免去"每种电路号克隆一台专属机器"
  - JEI/REI「+」键填充：配方语义直注入（读 GT 配方输入，不依赖 JEI 槽显示）——带号电路经
    AE2 的 `SET_FILTER` 包写服务端、客户端即时回显，落点为**第一个已启用空格**（材料行下方
    紧邻格），不与材料占位相撞
  - 已知限制：编码后的样板放回编码终端再编辑时，输入格看不到电路号——重新编码会丢号，
    需重放带号电路（后续可做样板载入还原）
- **星际采矿（火箭发射台）产出重构**
  - 输出 **3 槽 → 9 槽概率产出**（JEI 3×3）：保底 1 组（64）+ 8 档独立概率各 1 组
    85.36 / 73.16 / 65.33 / 57.64 / 46.87 / 38.88 / 26.66 / 13.33%，
    **期望 ≈ 5.07 组/次**（0.0.2 约 1.45 组）
  - 24 条配方（6 元素 × 档位）**改为纯数据包 JSON 单源**：此前代码版配方从未实际注册成功
    （JEI 一直显示 JSON 版），双源已删除，避免"代码改不动预览"的混乱
  - 输入与电压/时长不变：MK1 火箭 + 元素星图 + 编程电路（均不消耗）+ 气态氢 32,000 mB（消耗）
  - 超频改为自定义 modifier：每级时长减半、EU ×4，但**时长 20 秒封底**；失重环境 ×0.25
    太空加成保留
- **金属氢 / 液态氢**
  - 氢（patch 层 `ElementMaterials`）扩为**标准金属套**：锭 / 粒 / 块 / 粉 / 板 / 杆 / 长杆 /
    螺栓螺丝 / 环 / 箔 / 齿轮 / 小齿轮 / 圆盘全生成
  - 新增**液态氢**流体（`liquid_hydrogen`，20 K，0x86C8FF）挂 H 材料本体（同液氦先例）；
    主动流体键锁 GAS——气态氢配方不受影响
  - 封闭 6 处"流体 → 固体"固化配方生成点：液态氢不能直接固化出金属氢件
  - 气态氢流体名锁回材料名（修掉多流体化后走 `gas_generic` 模板的怪名）
  - 注：开发期曾挂发射台液氢配方（4,000 mB/次），随本次发射台配方单源化撤除，本版未恢复
    （流体本体保留）
- **维格纳-亨廷顿对顶砧（金属氢专属产线）**
  - 新多方块（13×13 底 ×26 高，用户导出结构逐字翻译：钻石晶格对顶砧 + 聚变玻璃外壳 + UEV 机壳端盖）：
    UEV 电压下把 **144 mB 液态氢压成 1 个金属氢锭**（200t、8,388,608 EU/t）
  - 能源仓位最多 **9** 个（空位可用 UEV 机壳顶替）；同档多仓照常享受 GTCEu 的 tier+1 超频红利
  - 新配方类型 `gtnecore:wigner_huntington_press`（JEI 内显示"液态氢 → 金属氢锭"）
  - **配方需超净环境**：塔高 26 格塞不进超净间 → 实战在 H 维护仓位装「超净维护仓 / 全能维护仓」
    （全能维护仓同时给超净 + 天文，本 mod 现成）
  - **自带 16 并行、且不额外耗电**：料不够就少跑几路（GT 并行语义），时长与 EU/t 不随并行数变化
  - **成型动态呈现**：成型后钻石晶格砧体隐形（结构幽灵占位，解体自动还原），由 glTF 动态渲染
    呈现上下两个对撞砧——配方进行时相向压合，快完成时砧间显现金属氢球（蓝），工作结束线性平滑回位
  - 机器面沿用蒸馏塔 overlay、机壳为 UEV 机壳；成型后部件显示为 UEV 机壳（GTM 1.12 风格）
- **氢 → UEV 超导线缆（材料增强）**
  - H 增加超导属性（V[UEV]、32A、零损耗）：GTCEu 自动生成 `wire_hydrogen` 裸线（1x~16x）
    与绕线机配方（金属氢锭 → 线）；超导线缆**没有包皮缆变体**（`cable_hydrogen` 不存在，
    与弦 Strium 同款处理）
  - UEV 档的 `CABLE` 配方组件改绑氢超导裸线：**UEV 时代所有用线缆的配方（机器外壳等）改吃金属氢**；
    11..16 档仍为铕电缆、17..21 档仍为弦
- **平台兼容与构建**
  - **GTMThings 1.6.0 接入** + VA `int[]`→`long[]` 强兼补丁：GTCEu 7.5.3 起 `GTValues.VA`
    为 `long[]`，GTMT 按 `int[]` 编译 → 进存档必炸的 `NoSuchFieldError`；patch 工具状态机
    扩展支持 `VA[tier]` 局部变量索引形式，产物 `gtmthings-1.6.0-patched.jar`
  - 构建链路修复：refmap 校验双名兼容（Mixin AP 产物在 `gtnecore.refmap.json` /
    `compileJava-refmap.json` 间漂移，此前表现为"启动崩溃"实为构建失败）
  - AE2 / 结构透明化等新增 mixin 纳入 `gtnecore.mixins.json`
